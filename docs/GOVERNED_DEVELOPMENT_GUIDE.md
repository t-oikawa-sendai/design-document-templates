本書は、7文書の記載先と、設定ファイルを任意で使う方法を説明する参考資料です。削除したり別の場所へ移したりせず、この配布物の一部として置きます。基本の記入・仕様変更・実装は [使用説明書](./STUDENT_USAGE_GUIDE.md) だけで始められます。非公開の原本を読めなくても、その基本の運用は成立します。

製品がファイルを自動で読むとは扱いません。使用するAIへ読むファイルを指定し、読めたパスと版を確認します。

## 1. 7文書の記載先とSSOT

SSOTは、正しい情報の管理元を一つに定める原則です。同じ仕様を複数の文書で決め直さず、正本を一つにします。他の文書はその正本の文書・節を参照します。

基本構成は `docs/design/README.md` と 01〜06 の7文書です。新しい設計文書を増やして似た説明を並べません。変更するときは、影響する文書と節を確認し、参照関係を崩しません。7文書があるだけでは効果は保証されません。記載先の指定、参照の維持、人による確認を続けます。

## 2. 設定なしの使用方法

1. `templates/design/` の7文書を、自分の `docs/design/` へ配置します。配布元の `docs/design/` はコピーしません。
2. 使用説明書の初期値で文書情報を初期化します。
3. 使用説明書の指示例を、今回の作業に合わせてAIへ渡します。
4. 新しい会話や別のAIへ切り替えるときも、最新の7文書と、対象・作業範囲を渡します。

AGENTS.md と CONSTITUTION.md が無いことは、不足でも停止理由でもありません。設定が無い場合は、7文書と明示した指示で進めます。対象のリポジトリは毎回指定します。

## 3. 設定ありの使用方法

設定ファイルが既にある利用先では、その現行ルールを読みます。設定を削除したり無視したりして、設定のない運用へ移しません。

| File（ファイル） | Role（役割） | Example（記載例） |
|---|---|---|
| `AGENTS.md` | AIの作業手順。読む対象と順序、作業の進め方を共通にできます。 | 作業開始時に `docs/design/README.md` と 01〜06 を読む。 |
| `CONSTITUTION.md` | 権限、承認、禁止事項などの共通ルール。仕様を守る作業範囲を共通にできます。 | 仕様変更は設計書を先に更新し、持ち主の承認後に実装する。 |

適用するAI・ツールの対応と設定を確認する必要があります。ファイルを置けば必ず読み込まれ、従うとは扱いません。製品ごとの対応と公式情報は [§8](#8-使用するaiごとの設定方法と公式情報) を参照してください。記載例は、設定ファイルを生成したり配布したりする指示ではありません。

設計7文書は、何を作るかの仕様を書く場所です。設定ファイルは、AIがどの順で読み、誰の承認に従うかを書く場所です。役割は異なります。

AIが読んだパスと版、理解した作業範囲を確認します。設定の更新と、設計書との矛盾も点検します。置くだけでは、AIが従うことは保証されません。

配布元自身は、既存の管理ルールで運用を続けます。利用先で設定が任意であることと、配布元の必須の管理資産は別です。

配布元の設定ファイルを、確認できないまま自分のリポジトリへコピーしないでください。承認者と適用範囲を確認できないコピーは導入しません。中央管理コピーの修正は、本書の作業では行いません。

## 4. 任意導入の手順

導入するかは、利用先リポジトリの持ち主が決める。

1. 持ち主が導入を決める。
2. 導入するルールの適用範囲、承認者、既存ルールとの整合を確認します。確認できない場合は導入しません。
3. 確認できたルールを、リポジトリのルートへ配置します。
4. 使用するAIに、そのファイルを読むよう指定します。
5. 読む順序と、今回の作業範囲の認識を確認します。

## 5. 初期指示と再開指示

開始時と再開時に、設定の有無を確認します。ある場合は既存ルールに従います。ない場合は7文書と明示した指示で進めます。対象リポジトリを毎回書きます。

初期指示の例:

```text
対象リポジトリ：<自分のRepository URLまたは名前>
このリポジトリに AGENTS.md と CONSTITUTION.md があるか確認してください。
ある場合は、その現行ルールを読み、読む順序と今回の作業範囲を示してください。削除や無視はしないでください。
ない場合は、最新の docs/design/README.md と 01〜06、および今回の作業範囲を読み、設定ファイルの不在を不足として止めないでください。
読めた文書と版、読めなかったものを示してください。
```

再開指示の例:

```text
対象リポジトリ：<自分のRepository URLまたは名前>
作業を再開します。前の会話だけを基準にせず、最新のファイルを読み直してください。
AGENTS.md と CONSTITUTION.md がある場合は、その現行ルールに従ってください。
ない場合は、最新の設計7文書と、今回の対象・作業範囲に従ってください。
何を確認できたか、何が未確認かを区別してください。
```

## 6. 設計変更から実装までの確認

順序は、設計書の変更、持ち主の承認、実装、差分と検証の確認です。文書を書かせる、仕様を変える、実装させる、の具体的な指示例は [使用説明書](./STUDENT_USAGE_GUIDE.md#6-aiへの指示) にあります。本書へ全文は再掲しません。

実装のあと、変更差分と検証結果、未確認事項を示させます。差分は Git で確認します。Git は、ファイルの変更履歴を管理する仕組みです。AIの完了報告だけを、確認済みとは扱いません。

## 7. デメリット

- 維持する対象が増える。設定と設計書の両方を更新し、矛盾がないか見る必要がある。
- 古いルールや、互いに矛盾したルールが残ると、AIも人も混乱する。
- ファイルを置いただけでは、遵守は保証されません。読んだことと、従った結果を確認します。

既存の設定を削除することは、これらの改善手段にしません。

## 8. 使用するAIごとの設定方法と公式情報

確認日：2026-10-10。利用できる機能はアカウント・契約・組織設定・提供状況によって異なります。

Skillsは「繰り返し使う指示を登録する機能」、Projectsは「関連する資料と指示をまとめる機能」です。以下の機能説明は公式情報に基づきます。7文書の登録・版数確認の方法は、本資料が提案する運用です。

| AI・機能 | Web版 | Desktop版 | 7文書を使う方法 | 公式情報 |
|---|---|---|---|---|
| Gemini（Skills） | 管理方法をSkillへ登録。必要なSkillを指定でき、関連する依頼では有効なSkillが自動適用される場合もある。 | Mac版もSkillsに対応。Windows版は今回確認した公式案内の対象外。 | 最新7文書を添付するか、Skillの参考ファイルとして登録する。参考ファイルを更新するときはSkill一式の再アップロードが必要。 | [Gemini Skills公式ヘルプ](https://support.google.com/gemini/answer/17094296?co=GENIE.Platform%3DDesktop&hl=en) |
| ChatGPT（Projects） | プロジェクトの指示へ管理方法を記載し、7文書をソースとして追加する。 | ChatGPTプロジェクトを利用できる。PCのフォルダを接続するローカルプロジェクトは通常のChatGPTプロジェクトとは区別する。 | プロジェクト内の会話で最新7文書を指定して読ませる。更新後は登録資料も最新にする。 | [Projects and chats](https://learn.chatgpt.com/docs/projects) |
| Claude（Projects／Skills） | プロジェクトの指示と資料を登録する。繰り返し使う作業にはSkillsも利用できる。 | 通常チャットのProjects・Skills・添付機能はWeb版と同様に利用できる。Cowork・Codeのローカル作業は別の利用方法として扱う。 | 最新7文書を登録し、対象文書を指定して読ませる。更新後は登録資料も最新にする。 | [Projectsの公式ヘルプ](https://support.claude.com/en/articles/9519177-how-can-i-create-and-manage-projects)、[Desktop版の公式案内](https://academy.claude.com/tutorials/navigating-the-claude-desktop-app)、[Skillsの公式ヘルプ](https://support.claude.com/en/articles/12512198-how-to-create-custom-skills) |

Gemini Skillsは段階的な提供であり、確認時点の公式案内では個人Googleアカウントを対象としています。機能が表示されない場合は、最新7文書と管理指示を会話へ直接渡してください。

`AGENTS.md`・`CONSTITUTION.md`をリポジトリに置くだけで、上記の通常チャットが自動的に読むとは扱いません。利用する機能へ指示・資料を登録するか、明示的に渡します。設定ファイルの自動読込みと7文書の全件読込みは別に確認します。

登録資料は利用時のコピーです。参照用コピーが古い版のままにならないよう、正本の変更後に更新してください。ローカル連携等による同期が確認できない場合は、自動同期を前提にしません。

開始時には、適用する管理ルールと読めたファイル名・版数、読めなかった文書をAIに示させます。具体的な開始指示は [使用説明書§6](./STUDENT_USAGE_GUIDE.md#6-aiへの指示)、FAQは [使用説明書§7](./STUDENT_USAGE_GUIDE.md#7-frequently-asked-questionsよくある質問) を参照してください。
