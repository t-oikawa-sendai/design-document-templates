## Purpose（目的）

このリポジトリの目的は、生徒が自身のプロジェクトの設計書を作成するためのテンプレートの配布及び使用方法のガイドラインである。

詳しい使い方は [生徒向け使用説明書](./docs/STUDENT_USAGE_GUIDE.md) を参照してください。今期は設計書の演習（手順A）を行います。

| 手順 | 行うこと | 参照先 |
|---|---|---|
| 1. 取得・配置 | 設計書READMEと01〜06の7文書を取得し、自分の `docs/design/` へ置く。 | [設計テンプレート](./templates/design/README.md)、[説明書§4](./docs/STUDENT_USAGE_GUIDE.md#4-取得と配置) |
| 2. 初期化 | 文書情報を自分の初期値へ変更し、リンクと画像を整える。 | [説明書§5](./docs/STUDENT_USAGE_GUIDE.md#5-自分の文書にする) |
| 3. AIと記入 | 課題文と最新文書を渡し、節ごとに相談して内容を確認する。 | [説明書§6](./docs/STUDENT_USAGE_GUIDE.md#6-aiと一緒に書く) |
